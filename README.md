## Features

- Cross-platform graphical user interface
- This project is a PDF Viewer and bookmark manager.
- There is a central bookmark panel which you can:
- Create, edit or delete groups and subgroups for categorasing bookmarks.
- Create, edit or delete bookmarks to pages from different pdf files.
- Clicking one bookmark results opening of containing file and displaying corresponding page.
- Search text within document.
- Copy and create spreadsheet from a table.

This project is under development. This is a usable version. Future versions will include some page viewing improvements as well as other improvements.

## How to use

- I am aware of usage explanation is bad. Sorry for that.
- You can use language selection on the upper right side of view.
- Open pdf document.
- Add group using Add group button. Write your Group Name and hit Tamam (means OK, İptal means )
- Group Name will be shown on Bookmarks pane.
- You can create subgroups under a group
- Goto page which you want to create bookmark
- Right click on group or subgroup and click Add bookmark.
- You can create groups, subgroups, bookmarks as you wish.
- If you click on a bookmark, the file and page will be opened.
- More explanatory usage will be prepared.
